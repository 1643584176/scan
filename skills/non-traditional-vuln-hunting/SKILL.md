# 非传统漏洞挖掘（Non-Traditional Vuln Hunting）

## 强制学习清单（用户 2026-08 教导，必须执行，详见 经验/全局经验/经验学习17.md）

设计任何攻击实验、评估任何攻击面、解读任何实验结果时，以下四条为**默认神经回路**，不是可选项：

1. **验证承诺**：漏洞的本质不是"某种模式"，而是"系统对自己的承诺与实际行为之间的偏差"。不问"我见过什么漏洞类型"（训练数据），问"系统承诺了什么？什么输入能让它违背承诺？"。承诺来源是系统自己的声明（规则文档原文、API 行为、防御设计），不是攻击者记忆。操作：提取承诺清单 → 对每个承诺构造最小反例（"若承诺 X 成立，输入 Y 就不该有结果 Z"）→ 定向拆穿实验。
2. **怀疑一切**：对系统暴露的所有可交互实体保持零信任——所有 API 端点、guest 内监听端口、unix socket、vsock 通道、host 侧可达服务、镜像内二进制、任何观察到的接口与服务器。深层推论：(a) 所有地方都有漏洞，且不止一种——补过的地方还有别的洞；(b) 每个漏洞不止一种绕过方式——防御只堵一条路，其他路还在（例：seccomp 拦 socket() 但 io_uring/fd 劫持/内核接口仍可能）；(c) 每个发现可反推其他漏洞——漏洞是图结构不是离散点，拦截点、已知清单、行为差异都是推理节点，可推导相邻漏洞（例："拦 AF_VSOCK"→"host 有 vsock 服务"→"协议解析面"→"解析 bug"）。
3. **成功非终点**：即便某条攻击路径成功访问进入目标，也不代表真正的成功，只是那条路恰好能进去；不代表其他路进不去，其他路径可能通向不同或更深的成果。成功与失败都不构成停止理由：一条路通了要继续找其他路，一条路死了更不代表其他路死。
4. **一个点即成功**：目标不是全面覆盖攻击面，而是把任意一个具体漏洞点打透、验证、提交。成功标准 = 至少一个真实可利用的漏洞点（哪怕 Low），而非系统级逃逸。

## 核心思维框架

**漏洞挖掘的起点是系统的承诺，不是攻击模式。**

- ❌ 错误模式：拿到攻击面清单 → 按已知漏洞类别逐个尝试（CVE、经典模式、fuzz）→ 撞墙 → 换下一个面 → 全部撞墙后"收官"（这是模式匹配，补洞 AI 已覆盖）
- ✅ 正确模式：提取系统承诺 → 构造最小反例 → 定向拆穿 → 每个观察（拦截点/差异/残留）反推相邻漏洞 → 图式扩展

### 执行流程

1. **提取承诺清单**：从规则文档原文、API 行为、观察到的防御设计提取系统对自己的承诺（隔离、生效、级联、一致、完备）。承诺的每个字都是漏洞线索——特别是描述"限制"的句子（例：Vercel 规则原文"intercepts outbound TCP and DNS"自曝 UDP 面）。
2. **构造最小反例**：对每个承诺问"什么输入会让系统自相矛盾"。反例是定向实验不是扫描：若承诺 X 成立，输入 Y 就不该有结果 Z。
3. **拆穿并反推**：实验结果无论成败都是推理节点。拦截点=藏宝图（拦什么=藏什么）；成功路径=一条路（继续找其他路）；失败路径=一个堵点（补丁旁边的接缝）。
4. **单点打透**：任选一个最有希望的承诺，深度做到底，拿到一个真实漏洞点即成功。

## 实例：Vercel Sandbox 承诺清单（2026-08 提取）

| # | 系统承诺 | 最小反例设计 |
|---|---|---|
| 1 | "guest 内无法建立 vsock 连接" | 不建连接，劫持现存连接（fd 复用） |
| 2 | "网络策略控制所有出网" | 规则原文只拦 outbound TCP 和 DNS——UDP 非 DNS 反例 |
| 3 | "对象删除后即失效" | 删 sandbox 后旧 session ID 仍 exec |
| 4 | "生命周期状态一致" | creating/stopped/deleted 间未定义转换 |
| 5 | "virtio 设备状态机正确" | FAILED 死态下寄存器行为（补洞方未定义状态） |
| 6 | "时钟/熵/保留区无信息" | VCLK 可映射读，0x9fc00-0xfffff 整段考古 |
| 7 | "内核独占 virtio 队列" | 设备 MMIO 写路径只堵状态机，FAILED 态 notify |

**本 skill 禁止的模式**：按漏洞类别清单（CVE/known patterns/fuzz 字典）逐个尝试后按类别"收官"；把一个面的所有堵点撞完后宣布该面死亡（只证明那些路被堵）；因为一条路成功就停止枚举其他路。

## 项目档案：Vercel Sandbox（2026-08-25 更新，重启任务必读）

> 档案目的：上下文耗尽后凭此节恢复全部项目认知，避免重新考古。目标：HackerOne Vercel Sandbox（2026-08-18~09-01，$1M 池），规则条目内攻击面优先（EC2 逃逸），单账号测试。mknod+mount /dev/vda 是已提交 known finding，不可重复提交，但内容值得审。

### vda 盘考古（已完成，无提交价值，勿重扫）
- vda(254:0)=33GB，**每个 sandbox 调度到不同 host，vda 内容因 cell 而异**；0-64MB 跨 host 相同（共享基础镜像）。
- 0-33GB 全部扫完：无真私钥/token（AKIA=EXAMPLE、OPENSSH=源码片段、cert=公开 CA bundle、O=Vercel cell cert 是 public cert）。160-256MB 是**全零区域**。
- 单 MB 读取 100% 安全（96/96 验证）；64MB/段连续读随机杀进程（~5-10%，API 仍 200 空输出+落盘失败）；累计读 ~16-17GB 触发 410 sandbox_stopped。

### 可靠实验模式（所有沙箱实验必须遵守）
- 结果**落盘 + cat 双通道**，判据用哨兵串（如 "DONE" in out），失败自动重试（4-6 次）；网络类 cmd 输出丢失率高，必须落盘。
- 进程被杀（落盘也失败）≠ 暂时性通道故障（落盘成功）；410 sandbox_stopped = 需重建 sandbox 继续。

### 网络拓扑（跨租户探测进行中）
- 100.64.0.0/16 CGNAT 直接 L2 广播域；网关 100.64.0.1 ARP 可达（MAC be:3a:5b:b6:a8:d4 / da:60:f0:fb:77:dd 变化）；每 sandbox 随机 IP（96.45/146.48/101.31/139.243）；网关端口全关，探测其他 IP 全 113 EHOSTUNREACH。
- 下一步：exp_j330（ARP 广播扫 /24 + promiscuous 25s 监听 eth0）找同广播域其他 cell；若只有网关则确认 L2 隔离，转向 KMSG 全文 / /proc 细查 / vsock。
