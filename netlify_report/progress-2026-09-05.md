## 4. ai-gateway 面(9/2 未测, 本轮新打) —— 设计完整 + plan gate, 免费 tier 无可测面
- GET /sites/{id}/ai-gateway/token: 自有 200 返回 HS256 JWT(kid 固定 32B, 2h 有效,
  claims={iss:netlify-api, site_id, request_id, source_ip, Domain:""}); 跨账号 404 / 匿名 401
- GET /accounts/{id}/ai-gateway/token: 403 "AI Gateway is not enabled for your account"(账号级需 enable)
- /.netlify/ai/(site 域): 匿名 401; 带 token 进 schema 校验 → provider/model 解析 → 403
  **"Direct AI Gateway access is not available on the free tier"**(free_direct_disabled, plan gate 服务端)
- **IP 绑定校验**: JWT source_ip claim 必须匹配请求源 IP —— 我们 IPv6 出口(2408:...)调 site 域(有 AAAA)
  恒 403 Mismatched source IP; 强制 IPv4(TCP 走 A 记录 + SNI 域名)即通过
  → 附产品缺陷: api.netlify.com 无 AAAA → IPv6 用户拿到的 token 恒为 IPv4 source_ip →
  IPv6 用户从 site 域(AAAA)调用恒 403 —— IPv6 可用性 bug(非安全, 未报)
- providers(匿名可读): anthropic/gemini/openai/openrouter, 各带 token_env_var + **url_env_var
  (ANTHROPIC_BASE_URL/OPENAI_BASE_URL 等) → 自定义 BASE_URL = SSRF 候选面, 但 free tier 在转发前被挡,
  需付费 plan 才能测
- JWT HS256 弱密钥: 44 候选全 miss(kid 本身也试了) → 伪造不可行
- 结论: 绑定+gate 完整; 免费账号无可用面(SSRF 候选被 plan gate 锁死)
