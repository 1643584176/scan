# scan

[English](#english)

这个仓库包含用于漏洞扫描和赏金猎取的工具和资源。

## 目录结构

- **common/**: 包含扫描的共享资源，包括常见的排除模式、漏洞模式和可重用载荷。
- **example_bounty/**: 一个赏金猎取项目的示例目录，包括发现、载荷、进度跟踪和排除项。
- **latest_vulnerability_reports/**: 用于从CVE来源获取和存储最新漏洞报告的脚本和数据。

## English

This repository contains tools and resources for vulnerability scanning and bounty hunting.

## Directory Structure

- **common/**: Contains shared resources for scanning, including common excluded patterns, vulnerability patterns, and reusable payloads.
- **example_bounty/**: An example bounty hunting project directory, with findings, payloads, progress tracking, and exclusions.
- **latest_vulnerability_reports/**: Scripts and data for fetching and storing the latest vulnerability reports from CVE sources.
