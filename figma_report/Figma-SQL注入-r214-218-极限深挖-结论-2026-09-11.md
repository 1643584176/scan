## 二、目标二：`/api/billing/notification_settings`（81 发）

### 2.1 数字解析器极限（A 段 27 发）

- **格式墙全貌**：`plan_id` 接受 `-?(0|[1-9]\d*)`——负号通（-1 / int64min）、正号拒（+）、前导零拒（00）、全角拒、逗号拒；**trim 全空白**（空格/tab/换行前后包裹均 200）。
- **位宽**：int64min / int64max / **max+1** / **uint64max(20位)** / **'9'×20** 全通过（403=查询走完）——30 位拒（400）；上限在 20-30 位之间未精确定位（超宽整数通道，非 int64）。
- **精度判别实验（杀手锏）**：TEAM_A=…213，float64 ULP=256，等价类 {…2208, …2213(+0), …2214(+1), …2144(网格值)}——**三发邻居值全 403**（精确通道，非 JS Number/浮点化，**无精度间隙可利用**）。
- **HPP 取尾**：`plan_id=A&plan_id=12345`→403；**颠倒→200**（取最后一个值，双发确证）。

## 三、本波新增防御指纹（19 条）

1. sha1 hex 校验大小写不敏感；2. %00 被 CloudFront 边缘拦截；3. `;` 无矩阵参数解析；4. 三形态 404 体系（纯文本 9B=路由无匹配 / JSON 123B=API 资源无 / SPA 826KB=方法或尾斜杠兜底）；5. 数字位=JSON 字面量+纯整数解析（quoted integer 报错族）；6. 整数解析器：`-?(0|[1-9]\d*)`+strip+位宽≥20；7. 超宽整数通道（非 int64，20 位通过 30 位拒）；8. HPP 取尾；9. JSON 重复键取尾；10. 枚举墙 strip 全空白（跨端点分裂）；11. ntype 查询过滤键+大小写敏感；12. 替换式写入（每次 PUT 新 UUID）；13. body/form 同一校验；14. 嵌套 JSON 不识别；15. XML 不解析；16. 越权写门 403（读写双态）；17. recipients 强制用户校验（无效全剔）；18. frequencies 非空必崩 500（环境 bug 路径）；19. 无 DELETE/无 id 子路由。

## 四、方法论沉淀（回流经验库）

1. **写面激活读面四步法**：建最小合法记录→读回确认→注入矩阵在有数据面上重打→自建自清。判别力来源：R1/R2 差分（真值有 meta vs junk 无 meta）是空数据面时代**永远测不到**的。
2. **时延盲注复打抖动纪律**：sleep 判决必须复打同一 payload 建抖动基线（本次抖动 400-2400ms，足以淹没伪信号）；判决用「多形态 × 多方言 × 上下文闭合」矩阵。
3. **精度等价类判别**：大整数通道用 float64 网格值/邻居值区分「JS Number 通道（有间隙）」vs「精确通道（无间隙）」。
4. **枚举墙空隙扫描**：strip 语义逐空白字符测（空格/tab/换行），行为跨端点分裂不可外推。

### 4.3 意外收获：服务端防御链全貌（T1/T2 错误全文）

```
Error in route typechecking for /api/files/:file_key/videos/:sha1/thumbnails:
Error occurred during parsing: Error parsing JSON @1:27: Non-number characters in quoted integer
```

- **「route typechecking」= Sinatra 路由层把参数按 JSON 字面量解析后做类型断言**——r214「quoted integer」家族的真身（`"1"`=quoted integer 拒、`0--`=JSON 语法错误）

| **尾 U+202E（RLO）** | **200** | **Bidi 控制符被删除**（首尾都删：前 RLO 也 200） |

**宽容机制全谱终版：①首尾删除（ASCII 空白/NUL/U+202E）②中段 NUL 截断（前段为值）③路径参数数字前缀截断（r239）——三者全部「丢弃性」，丢弃后均为纯数字或空，无注入窗口。**

### 10.3 新错误模板（第 6 个）⭐
