### 2.1 `related_links` 面（Dev Mode handoff 链接）

**JS 形态（_q4 逆向）**：

```
POST /api/files/related_links                    {file_keys: [fk,...]}          ← 批量读
POST /api/files/${fileKey}/related_links         {node_id, link_name, link_url, lg_optimistic_mutation_uuid}
PUT  /api/files/${fileKey}/related_links         {node_id, link_id, new_link_name, new_link_url, link_preview_json?}
DEL  /api/files/${fileKey}/related_links?node_id=&link_id=
PUT  /api/files/${fileKey}/related_links/link_preview  {node_id, link_id, link_preview_json}   ← any schema 任意 JSON
响应 schema: {id, node_id, file_key, link_name, link_url, is_user_override, link_preview_json: any}
```

```js
postRecentActivity(e){return n.Ay.post(n.Ay.url`/api/files/${e.fileKey}/recent_activity`,
```

|---|---|---|---|
| l13 / l14 | own/UNK1 × `R196Q_PROBE` | 400 `Unsupported activity_type` | 枚举白名单（大写下划线名不含在内） |

## 三、防御模型终版（跨面归纳）

**七层结构**（按拦截顺序）：

```
1. route typecheck        声明式参数类型校验（数组语法/JSON 解析级）
   └ 指纹: Error in route typechecking ... Expected string/Number/Array/JSON @L:C
2. Rails 强参数            expect/permit + 双解析路径
   └ 指纹: Invalid query parameters: expected Array (got String / Rack::QueryParser::Params)
3. 参数映射层             外部名→内部名（file_type→editor_type）
   └ 指纹: 消息暴露内部名
4. schema/白名单/枚举     精确匹配（不归一化）/静默回退/trim 分裂/清洗存活
   └ 指纹: Invalid sort_column parameter / must be 'asc' or 'desc' / 静默回退
5. 参数化（搜索字符串位） 全静默 + 零时延 + 结果无差分
   └ 终判: pg_sleep 嵌入合法表达式零延迟
6. opaque token           游标/cursor 服务端生成（base64+JSON / max_nesting=100）
   └ 指纹: 浅层 500 + rescue 边界
7. 权限门                 403 家族 + 反枚举默认分支 + 计划门
   └ 指纹: no_permission / no_permission_contact_org_admin / 403-404 不可辨
```

**分裂行为备忘**（同名家族不可跨端点外推）：
- 枚举位：`account_type_request ` 尾空格拒（精确） vs `credits_used ` 放行（trim）——逐端点独立确认
- 403 模板：`You don't seem to have permission` vs `...Contact your organization administrator`——门类型不同
- 处置模式：白名单拒绝（sort_column）/ 静默回退（file_type）/ 清洗存活（folder_search query）/ 静默宽容（related_links 批量）

## 四、服务端缺陷累积（低危观察，均已记录未提交）

| # | 缺陷 | 触发 | 影响 | 证据 |
|---|---|---|---|---|
| 1 | cursor 浅层 500 | 任意"合法 JSON 非 null"的 base64 游标 | 未处理异常（无信息泄露，app;dur 与 200 同量级） | r196ak-al-an |
| 2 | related_links 批量无差别宽容 | 任意 file_keys（含 foreign/注入元素/嵌套） | 全 200 空，越权探测不可辨（也可能为静默丢弃设计） | r196ao-ap-aq |
| 3 | 双 403 模板泄露门类型 | 对照 no_permission vs no_permission_contact_org_admin | 可探测端点是"功能门"还是"组织管理员门" | r196ao-aq |
| 4 | recent_activity 校验顺序 | 参数校验先于权限（400 对 foreign 一视同仁） | 可在无权文件上无害探测枚举（信息量极低） | r196ap |
| 5 | recent_search null 任意字段 → 500 | `{x: "\x00"}` 等 | 崩点（无泄露） | r89/r196ac 族 |
| 6 | versions 游标解析 500 | before 时间格式边界 | 浅层崩（快）= 解析层拦 | r140-r153 |

**裁决**：以上均无信息泄露、无数据影响、无越权结果——记录画像，不单独成报告。
