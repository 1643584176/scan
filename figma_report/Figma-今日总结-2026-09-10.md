### 1.2 related_links 面结论

| 子面 | 行为 | 判定 |
|---|---|---|
| 批量 `POST /api/files/related_links` | 全输入（own/foreign/注入元素/嵌套数组/裸串）→ 200 `meta:[]` 零差分零时延 | **静默宽容**（集合语义，查不到即忽略）；判别面未激活（自有文件无 links 数据），不写"参数化安全" |
| 单文件 POST/PUT/DELETE | 自有文件也 403 `error.no_permission` | **Dev Mode 计划门**——排除权限/形态错误；注入不可达 |
| `link_preview_json`（any schema 任意 JSON） | 未达（计划门挡住） | 留待 Dev Mode 账号 |

### 1.3 recent_activity 面结论

- JS 逆向拿到 **7 个 activity_type 真值**（file_seen / design_file_seen / whiteboard_file_seen / file_edit / design_file_edit / whiteboard_file_edit / dev_mode_file_seen）
- 实测服务端接受子集 ⊇ {design_file_seen, dev_mode_file_seen}；file_edit 拒
- **参数校验先于权限**：foreign 文件 + 非法枚举 → 400 `Unsupported activity_type`（与 own 相同）；foreign + 合法枚举 → 200
- SQLi 视角：值位=枚举白名单（V4），无注入空间

### 1.4 activity_logs/export 面结论

- 全 403 `error.no_permission_contact_org_admin`（含空 body 与全部注入 payload）
- **权限先于参数解析**（org admin 审计门）；与 related_links 的 `error.no_permission` 是两种 403 模板

### 1.5 环境规律确证

- **RST 瞬态**：每波会话首 1-5 发偶发 ConnectionResetError(10054)，重打全通——网络层瞬态，非内容触发
- **403 双模板**：`no_permission`（功能门）vs `no_permission_contact_org_admin`（组织管理员门）——可探测门类型
